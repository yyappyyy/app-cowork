# 📊 家計簿スプレッドシートテンプレート

Etsy販売向けのプロフェッショナルな家計簿（Household Budget）Googleスプレッドシートテンプレートです。

## ✨ 特徴

- **年間ダッシュボード**: 収入・支出・貯蓄の年間サマリーとグラフ
- **月別管理シート（12ヶ月分）**: カテゴリ別の予算・実績管理、日別支出記録
- **固定費・サブスクリプション管理**: 毎月の定期支払いを一覧管理
- **貯蓄目標トラッカー**: 目標金額と進捗の可視化
- **使い方ガイド**: 初心者でもすぐに始められる説明付き

## 📋 シート構成

| シート名 | 内容 |
|---------|------|
| ダッシュボード | 年間サマリー、月別比較グラフ |
| 1月〜12月 | 月別の収入・支出管理、日別記録 |
| 固定費・サブスク管理 | 家賃・光熱費・サブスクの一覧 |
| 貯蓄目標 | 貯蓄目標と達成率の管理 |
| 使い方ガイド | テンプレートの使用方法 |

## 🚀 使い方

1. `家計簿テンプレート.xlsx` をダウンロード
2. Googleドライブにアップロード
3. 「Googleスプレッドシートで開く」を選択
4. 各月のシートに収入・支出を入力
5. ダッシュボードで年間の収支を確認

## 💡 ポイント

- **数式不要**: すべて自動計算されます
- **カスタマイズ自由**: カテゴリや色を自由に変更可能
- **日付なし**: いつからでも始められます
- **印刷対応**: サマリーページの印刷にも対応

## 📁 ファイル

- `家計簿テンプレート.xlsx` - メインのスプレッドシートファイル（Google Sheets互換）

## 🔧 再生成

テンプレートを再生成する場合:

```bash
pip install openpyxl
python3 scripts/create_budget_spreadsheet.py
```
